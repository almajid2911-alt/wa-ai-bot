# Folder Brosur & Gambar Produk

Taruh file gambar brosur atau promo di dalam folder ini (`assets/brosur/`).

Contoh nama file yang didukung:
- `brosur-indihome.jpg` atau `brosur-indihome.png` (Brosur umum / pricelist lengkap)
- `brosur-1p.jpg` (Brosur khusus paket internet 1P)
- `brosur-2p.jpg` (Brosur khusus paket internet + TV 2P)

Ketika pelanggan meminta "minta brosur", "lihat fotonya", atau "ada gambar pricelist?", bot AI akan otomatis mendeteksi dan mengirimkan file gambar dari folder ini langsung ke chat WhatsApp pelanggan.
